## About

Portfolio website for **Jagruthi Mothukuri**, Senior Tableau Analyst at Univar Solutions with 12+ years of experience in Business Intelligence and Data Visualization.

---

## Sections

| Section | Description |
|---|---|
| **Hero** | Animated particle background with name, title & location |
| **About** | Bio, skills, and animated stat counters |
| **Experience** | Timeline of career history |
| **Education** | MS from University of South Alabama & JNTU |
| **Certifications** | 12 Tableau, Alteryx & Power BI certifications with filter |
| **Recommendations** | Auto-playing slider with 7 LinkedIn recommendations |
| **Contact** | LinkedIn, GitHub & location links |

## Tech Stack

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)

- Responsive design (mobile, tablet, desktop)
- Smooth scroll-reveal animations
- Interactive particle canvas in hero section
- CSS custom properties & Grid/Flexbox layout

## Features

- Animated particle network background
- Scroll-triggered fade-in animations
- Certification filter (All / Tableau / Other)
- Auto-playing testimonial slider with swipe support
- Sticky navbar with scroll state
- Animated number counters
- Fully responsive & mobile-friendly
